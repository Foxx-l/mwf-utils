# MWF Utils v2.2.0 UI and Rotation Safety Update

## Included

- Public rotation UI with completed (`✅`), next (`➡️`), and upcoming (`•`) events.
- Prominent relative next-event summary.
- Short local date/time rendering and a local-time footer.
- No public revision number.
- Sync, Edit, confirmed Advance, confirmed Reset, and Undo controls.
- Last 10 rotation states retained for Undo.
- Automatic timestamped rotation backups in `data/backups` (last 10 retained).
- Edit-preview change summary.
- Configurable event time in the editor and `ROTATION_EVENT_TIME` env fallback.
- Rich panel status showing the displayed month window and Undo count.
- Startup summary for data storage, rotation synchronization, and schedulers.
- Rotation diagnostics in Healthcheck.
- All previous v2.1 fixes retained.

## Install on top of v2.1.x

Download `mwf-utils-v2.2.0.zip` to Downloads, then paste the one-line PowerShell command supplied with the archive. It backs up `.env` and `data`, overlays the update, verifies it, and restarts PM2.

After installation, run `/panel` again to receive the new controls. Old panel messages contain old menu values.

Expected verification: 3 suites, 17 tests, no lint errors, 0 vulnerabilities.
